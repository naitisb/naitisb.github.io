# naitisb.github.io

Personal/professional website for Naiti S. Bhatt, built as a plain static HTML/CSS/JS site (no build step, no Jekyll). Pages: Home, Projects, CV, Research, Photos, Contact. `portfolio.html` and `presentations.html` are redirect stubs for the old URLs.

Deployed to GitHub Pages by the Actions workflow in `.github/workflows/deploy-pages.yml` on every push to `main`. To preview locally, serve the directory with any static file server (e.g. `python3 -m http.server`) — the pages also work by opening the `.html` files directly in a browser.
